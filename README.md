# TaskFlow Helper

Privacy policy: see [index.html](index.html).

## Install on Firefox for Android (sideload)

Open this link in **Firefox for Android** to install the signed add-on:

**https://github.com/jeetbij/taskflow-helper-privacy/releases/download/v0.8.2-android/82cdabecbdc14bf4a3a2-0.8.2.xpi**

Firefox will prompt to add the extension. After installing, find it under **≡ → Extensions**.
